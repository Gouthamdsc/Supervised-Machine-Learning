# Supervised-Machine-Learning
Machine Learning  Project on house price prediction. In this project we are going to predict the house prices using various machine learning models from those we choose the best performing model that gives the accuerate estimated prices.
The code and dateset has been given in this repository go through them.
To ececute the given code in the jupyter lab we need to have necessary libraries mentioned in requirements.txt file with out installing these libraries we may get errors. Even after installing each library if you still get any error consider installing seaborn library fro having better results while using matplotlib library. In requirements.txt file i have included the dataset source link and the dataset have been uploaded in this repository itself.
