# Supervised-Machine-Learning
Machine Learning  Project on house price prediction. In this project we are going to predict the house prices using various machine learning models from those we choose the best performing model that gives the accurate estimated prices.
The code and dateset has been given in this repository go through them.
To ececute the given code in the jupyter lab we need to have necessary libraries mentioned in requirements.docx file with out installing these libraries we may get errors. Even after installing each library if you still get any error consider installing seaborn library fro having better results while using matplotlib library. In requirements.docx file I have included the dataset source link which is a open soure dataset publically available in kaggle and the same dataset have been uploaded in this repository itself.
